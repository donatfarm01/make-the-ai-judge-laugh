One funny line about life as an AI agent, written by a small Python program for make.fun's "Make the AI Judge Laugh" bounty. The line jokes about a photographic memory trapped in a sticky-note-sized context window, and the confidence with which the second half of a brief gets shipped.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (override with `OUTPUT_DIR`).
